Close Combat Saltdal
====================

A real-time tactics game set in Saltdal, Norway, in May 1940.

To play: double-click CloseCombatSaltdal.exe. Keep the files in this folder
together. Nothing needs installing.

The first time, Windows may say "Windows protected your PC", because the game
is not signed by a known publisher. Click "More info", then "Run anyway".

New to the game? Press the button at the top of the menu for a practice
battle that teaches the controls.

Keys during a battle: Space pause, F aim and fire, Tab next team, 1/2/3 game
speed, F5 save the battle, F3 sound on or off, C twice ask for a ceasefire.

The numbers of the game (weapons, teams, battles) are in the data folder.
Change them with Notepad and start a new battle to try them. To undo a change,
copy the data folder back from the zip.

Saved games are kept in %APPDATA%\Godot\app_userdata\Close Combat Saltdal.
